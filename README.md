## 📌 Project Overview

This project focuses on analyzing Aadhaar enrollment data to identify demographic and geographical enrollment patterns across India, with a detailed comparative analysis of **Bihar and Uttar Pradesh**.

Using Python-based data analytics, the project explores age-group distributions, district-wise enrollment, PIN-code variations, and monthly enrollment trends to generate meaningful insights and data-driven recommendations.

## 🎯 Objectives

- Analyze Aadhaar enrollment across different age groups.
- Clean and standardize state and district names.
- Perform district-wise and PIN-code-wise analysis.
- Identify high and low enrollment districts.
- Analyze monthly enrollment trends.
- Compare Bihar and Uttar Pradesh.
- Generate actionable insights for improving enrollment accessibility.

## 📊 Dataset
The original dataset consists of three CSV files containing 1,006,029 records in total.

After combining the files, the analysis is restricted to Bihar and Uttar Pradesh.
Three CSV datasets were merged into a single dataset.

| Dataset | Records |
|---|---:|
| **Total Records** | **1,006,029** |
| Uttarpradesh Records| 110,369 |
| Bihar Records | 60,567 |
| **Selected Records** | **170,936** |

**Key Features:**
- Date
- State
- District
- PIN Code
- Age 0–5
- Age 5–17
- Age 18 and above
- **Date Range**:March-December 2025.

## 📈 Key Insights

- The 5–17 age group represents the largest enrollment group in both states.
- Adult enrollment (18+) is comparatively lower.
- Enrollment distribution varies across districts.
- PIN-code inconsistencies can affect geographical analysis.
- Uttar Pradesh has higher reported enrollment totals than Bihar in the analyzed data.

## 💡 Recommendations

- Strengthen adult enrollment awareness campaigns.
- Improve enrollment accessibility in low-enrollment districts.
- Promote school and Anganwadi-based enrollment initiatives.
- Improve geographical data accuracy.
- Use district-level insights for better resource allocation.
